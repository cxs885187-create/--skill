# 女娲补天

一个面向大学生期末考试突击复习的 Codex Skill。

女娲补天不是“自动押题工具”，也不是“万能学习助手”，而是一套半自动应试复习工作流：把课件、讲义、教材、题库、往年题和补充资料整理成可复习、可自测、可迭代的 Markdown 笔记库。

## 适合什么场景

- 期末快到了，资料很多但很乱。
- 一个文件夹里混着多门课的 PPT、PDF、题库、教材和图片。
- 想先按课程归档，再一次只处理一门课。
- 想把资料压缩成能直接复习的专题卡，而不是只有目录索引。
- 想根据题库、作业、往年题反推高频题型。
- 想用多轮提问定位自己到底是定义不会、公式记不住、题型认不出，还是步骤不稳。
- 想在看不懂抽象内容时，引入开源讲义、GitHub 教材/题库、图解和可视化辅助理解。

## 核心原则

- 一门课一门课处理：不要一次性生成多门课完整复习包。
- 先问考试时间：备考时间决定输出粒度和复习策略。
- 材料先归档：文件模式下要真正建立课程材料文件夹，而不是只在索引里写分类结论。
- 证据分级：区分用户材料、老师资料、真题题库、学校开源题库、通用 GitHub 讲解。
- 不自动判分：Skill 给参考答案和得分点，最终由用户自评。
- 笔记必须能复习：如果一个文件不能让用户拿起来开始背、做、查错，它就不合格。

## 功能

### 资料归档

在文件模式下，Skill 会优先把资料整理成类似结构：

```text
workspace/
├─ to-confirm/
├─ 高等数学A/
│  ├─ materials/
│  ├─ index.md
│  ├─ 核心骨架.md
│  ├─ 自测与错因.md
│  └─ 冲刺摘要.md
└─ 思想道德与法治/
   └─ materials/
```

低置信材料会进入 `to-confirm/` 或被明确标记为待确认。

### 课程骨架

证据优先级：

1. 用户提供的大纲、老师重点、课件。
2. 用户教材和作业。
3. 用户提供的真题、题库。
4. 学校相关的开源题库或往年题仓库。
5. 官方/出版社/权威课程页面。
6. 通用 GitHub 讲义或开源教材。

通用 GitHub 仓库只能作为“讲解增强源”，不能替代老师资料或考试范围判断。

### 学校定向 GitHub 搜索

如果用户提供学校名称，Skill 会优先搜索学校相关的开源题库、往年题、作业仓库。

只有同时满足这些条件时，才可作为较强题型参考：

- 学校匹配
- 课程名称或课程代码匹配
- 材料类型清楚，例如 final、midterm、homework、quiz、question bank
- 年份或学期尽量可追踪

否则只能标记为 `explanation aid` 或 `low confidence reference`。

### 专题卡型笔记

对重积分、曲线积分、曲面积分、无穷级数等内容，Skill 不应只生成索引，而应生成专题卡。

每张专题卡至少回答四件事：

- 背什么
- 怎么做
- 哪些地方最容易错
- 怎么自测

示例：

- `重积分专题.md`
- `曲线曲面积分专题.md`
- `无穷级数专题.md`

### 可视化辅助

遇到难以直观理解的内容时，Skill 可以生成：

- ASCII 草图
- Mermaid 图
- 表格
- 区域、投影、法向说明
- 本地渲染图或生成图片，如果环境支持

适合可视化的内容包括：

- 重积分区域
- 曲线积分方向
- 曲面积分法向
- 向量场
- 坐标变换
- 空间几何
- 离散数学中的图、关系、路径

### 自测与薄弱点定位

Skill 不做权威自动判分。

推荐流程：

1. 一轮给 4 到 5 题。
2. 用户先闭卷回答。
3. Skill 展开参考答案或评分点。
4. 用户自评为 `know` / `partial` / `dont know`。
5. Skill 根据自评继续追问，定位薄弱层。

薄弱层包括：

- 定义不会
- 公式记不住
- 题型认不出
- 步骤不稳定

如果连续 3 题都是 `dont know`，应停止继续出题，回到对应专题卡重建。

## 不做什么

- 不保证押中考试题。
- 不把 GitHub 仓库当成默认考试范围。
- 不用随机网页替代教材或老师资料。
- 不在证据不足时声称“这是必考题”。
- 不把一门课拆成几十个难以导航的小文件。
- 不把所有内容塞进一个超长 Markdown，除非是 24 小时极限模式。

## 功能的理论支持与经典方法

| 功能 | 理论支持或经典方法 | 在 skill 中的体现 |
| --- | --- | --- |
| 一门课一门课处理 | 认知负荷理论、目标屏蔽、单任务聚焦 | 在当前课程稳定前，不同时生成多门课的完整复习包。 |
| 先问考试时间 | 倒排计划法、时间盒、应试约束规划 | 根据考试日期和剩余时间选择 7 天、3 天或 24 小时模式。 |
| 资料归档 | 信息分块、来源追踪、证据本位学习 | 按课程分组材料；低置信文件进入 `to-confirm/`，不静默合并。 |
| 先建课程骨架 | 先行组织者、图式理论、概念图、建构性对齐 | 先建立 course/chapter/topic/subtopic 层级，再写压缩摘要。 |
| 证据分级 | 证据层级、三角互证、来源批判 | 用户材料优先于学校开源仓库，学校开源仓库优先于通用讲解源。 |
| 学校定向 GitHub 搜索 | 情境化学习、近迁移、生态效度 | 同校同课资料可以增强题型证据，但必须满足明确匹配条件。 |
| 专题卡型笔记 | 康奈尔笔记法、主动回忆、分块学习、样例学习效应 | 每张专题卡回答“背什么、怎么做、易错点、怎么自测”。 |
| Cornell 风格问题块 | 康奈尔笔记法、测试效应、生成效应 | 用问题提示和折叠参考答案，让用户先回忆再看答案。 |
| 冲刺模式计划 | 倒排法、帕累托原则、间隔重复、艾宾浩斯遗忘曲线 | 时间越短，越偏向高价值主题、提取练习、错题复盘和反复回忆。 |
| 可视化辅助 | 双编码理论、多媒体学习理论、空间推理外化 | 只在区域、方向、法向、坐标变换、图结构等内容确实降低理解成本时使用图示。 |
| 外部讲解增强 | 费曼技巧、精加工编码、类比学习 | 开源讲义和 worked examples 只用于直觉、记忆钩子和误区提示，不改考试范围。 |
| 自测 | 主动回忆、检索练习、测试效应、形成性评价 | 先让用户闭卷作答，再展开参考答案或评分点。 |
| 用户自评 | 元认知校准、自我调节学习 | 用户用 `know`、`partial`、`dont know` 标记，Skill 据此决定下一步。 |
| 薄弱点定位 | 诊断性评价、掌握学习、错误分析 | 追问定义、公式、识别、步骤，定位真正卡住的层级。 |
| 自测熔断 | 认知负荷管理、脚手架教学、挫败感调节 | 连续 `dont know` 时停止加题，回到专题卡重建。 |
| 谨慎使用“掌握”语言 | 元认知偏差控制、评价有效性边界 | 使用 `temporary recall ok` 等保守状态，不凭 Skill 自己的判断宣布掌握。 |
| 增量资料更新 | 间隔重复、遗忘曲线友好复习、学习日志 | 复用旧 `index.md` 和笔记；新材料只更新受影响部分。 |

## 安装方式

将 `nuwa-mends-the-sky/` 复制到你的 Codex skills 目录。

Windows 示例：

```powershell
Copy-Item -Recurse ".\nuwa-mends-the-sky" "$env:USERPROFILE\.codex\skills\nuwa-mends-the-sky"
```

然后重启 Codex，或开启新的 Codex 会话。

## 使用示例

```text
使用 $nuwa-mends-the-sky。
我把高数、思政和离散数学的复习资料都放在这个文件夹里。
我的学校是 XX 大学。
高数考试时间是 7 月 1 日。
请先只处理高等数学 A。
```

Skill 应该先：

- 确认文件模式或纯对话模式
- 确认考试时间
- 只处理一门课
- 按课程归档材料
- 建立 evidence-based 课程骨架
- 必要时搜索学校相关开源题库
- 生成能直接复习的专题卡、自测与冲刺摘要
